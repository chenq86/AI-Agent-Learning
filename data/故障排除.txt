200 Fault Detection and Repair Items for Sweeping/Sweeping-and-Mopping Robot Vacuums

1. Fault Phenomenon: The robot does not respond when powered on, and the indicator light is off; Detection: Check if the power adapter is securely plugged in, if the power cord is damaged, and if the battery is properly installed; Repair: Replace with an intact power cord, reinsert the battery, ensure the charging dock is powered, and contact after-sales service to inspect the mainboard if there is still no response.

2. Fault Phenomenon: The robot shuts down automatically immediately after powering on; Detection: Check if the battery is depleted, if the body is overheating, and if the battery is swollen; Repair: Retry after fully charging, move to a ventilated area to cool down, and immediately replace with an original battery if it is swollen.

3. Fault Phenomenon: The robot cannot connect to WiFi; Detection: Confirm that the phone and robot are connected to the same 2.4G network, check if the WiFi password is correct, and check if the robot's WiFi module is obstructed; Repair: Restart the router and the robot, re-enter the WiFi password, and wipe dust from the WiFi module area.

4. Fault Phenomenon: The APP cannot control the robot; Detection: Check if the network connection is normal, if the APP is the latest version, and if the robot is in standby mode; Repair: Switch networks, update the APP, restart the robot, and rebind the device.

5. Fault Phenomenon: The robot frequently collides with furniture during cleaning; Detection: Check if the obstacle avoidance camera/sensors have dust or water stains, and if the bumper bar is stuck; Repair: Wipe the obstacle avoidance components with a dry cloth, gently press the bumper bar to confirm normal rebound, and clear surrounding obstacles.

6. Fault Phenomenon: The robot does not move or moves slowly; Detection: Check if the drive wheels or caster wheel are tangled with hair or debris, if the wheel assembly is stuck, and if the floor is too slippery; Repair: Clean tangles from the wheel assembly, apply a small amount of dedicated lubricant, and test on a dry floor.

7. Fault Phenomenon: Suction power drops significantly; Detection: Check if the dust bin, filter, or air duct is blocked, if the main brush is tangled with debris, and if the suction port is obstructed; Repair: Clean each blocked part one by one, cut away hair tangled in the main brush, and ensure the suction port is free of foreign objects.

8. Fault Phenomenon: The main brush does not rotate; Detection: Check if the main brush is jammed by foreign objects, if the motor wiring is loose, and if the main brush motor is faulty; Repair: Clear debris from the main brush, reinstall the main brush, and contact after-sales service to inspect the motor if it still does not rotate.

9. Fault Phenomenon: The side brush does not rotate; Detection: Check if the side brush is properly installed, if the shaft is tangled with hair, and if the side brush motor is abnormal; Repair: Reinstall the side brush, clear debris from the shaft, and replace the side brush motor if there is abnormal noise.

10. Fault Phenomenon: The robot cannot find the charging dock; Detection: Check if there are obstructions around the charging dock, if the return-to-charge sensor has dust, and if the infrared signal from the charging dock is normal; Repair: Clear obstacles within 3 meters around the charging dock, wipe the return-to-charge sensor, and reposition the charging dock.

11. Fault Phenomenon: The indicator light flashes during charging, and it cannot charge normally; Detection: Check if the charging contacts are oxidized or dusty, if the power adapter is faulty, and if the battery is damaged; Repair: Wipe the charging contacts with a dry cloth, replace with a matching power adapter, and replace the battery if it is damaged.

12. Fault Phenomenon: Battery life decreases significantly; Detection: Check the battery's age, whether overcharging or deep discharging occurred, and if the battery is swollen; Repair: Avoid overcharging and deep discharging, perform regular full charge/discharge cycles for calibration, and replace with an original battery if capacity is below 50%.

13. Fault Phenomenon: Map building is incomplete or the map is chaotic; Detection: Check if there are reflective objects in the environment, if there are too many movable obstacles, and if sensors are abnormal; Repair: Cover reflective objects, clear movable obstacles, delete the old map, and rebuild the map.

14. Fault Phenomenon: The robot frequently pauses during cleaning; Detection: Check if the dust bin is full, if the battery level is low, and if sensors are obstructed; Repair: Empty the dust bin, fully charge the robot, and wipe dust from the sensor surfaces.

15. Fault Phenomenon: The water tank leaks during mopping; Detection: Check if the tank lid is tightened, if the sealing ring is aged or detached, and if the outlet pipe is blocked; Repair: Tighten the tank lid, replace the aged sealing ring, and unclog the outlet pipe.

16. Fault Phenomenon: No water comes out during mopping; Detection: Check if the tank has water, if the water flow is set to the lowest level, and if the outlet pipe is blocked; Repair: Add clean water, increase the water flow setting, and gently unclog the outlet pipe with a toothpick.

17. Fault Phenomenon: The electric mop pad does not rotate; Detection: Check if the mop pad is tangled with debris, if the mop motor is properly installed, and if the motor wiring is loose; Repair: Clear debris from the mop pad, reinstall the mop motor, and contact after-sales service to troubleshoot wiring issues.

18. Fault Phenomenon: The automatic mop washing function fails; Detection: Check if the cleaning station has water, if the dirty water tank is full, and if the cleaning brush is blocked; Repair: Add clean water, empty the dirty water, and clear tangles from the cleaning brush.

19. Fault Phenomenon: The robot emits "beep beep beep" alarm sounds; Detection: Check the indicator light code on the body, APP fault prompts, and inspect corresponding parts (such as dust bin, filter, battery); Repair: Clean the corresponding parts as prompted and restart the robot.

20. Fault Phenomenon: Anti-drop function fails, posing a risk of falling; Detection: Check if the bottom anti-drop sensors have dust and if the sensors are damaged; Repair: Wipe the sensors, test on a flat surface, and contact after-sales service for replacement if damaged.

21. Fault Phenomenon: The robot's cleaning path is chaotic and irregular; Detection: Check if planned cleaning mode is enabled, if the map is complete, and if there are new obstacles in the environment; Repair: Enable planning mode, rebuild the map, and clear new obstacles.
